HR Contact Finder 개인정보처리방침

시행일: 2026년 11월 9일

적용 대상: HR Contact Finder Chrome 확장 프로그램 사용자 배포판

1. 운영 주체와 적용 범위

HR Contact Finder는 개인 개발자 KimJinHyuk이 개발·운영하는 개인 개발 프로젝트입니다. 기관 내부 시스템에 접근할 수 있는 사용자가 업무에 필요한 구성원 연락처, 조직도 및 복무정보를 조회하도록 지원합니다.

이 방침은 확장 프로그램이 처리하는 정보의 항목, 목적, 저장·전송 방식 및 삭제 방법을 설명합니다. 기관 HR API·ERP·그룹웨어의 원본 데이터 운영과 서버 로그 관리에는 해당 기관 시스템의 정책이 적용됩니다. 확장 프로그램의 설치나 사용은 기관 시스템 또는 개인정보에 대한 추가 접근·이용 권한을 부여하지 않습니다.

2. 처리하는 정보와 이용 목적

구성원 및 부서 정보

  • 처리 항목: 기관 HR API가 제공하는 이름, 사번, 전화번호, 이메일, 소속, 직위, 담당업무 및 API 응답에 포함된 부가 필드
  • 처리 목적: 구성원 연락처 검색, 상세 정보 표시 및 연락처 갱신
  • 처리 방식: API 응답의 행 전체를 로컬 캐시에 저장합니다. 표시 필드 선택은 화면에 보이는 항목을 조정하며, 저장 대상을 해당 필드로 제한하지 않습니다.

복무정보 및 조회 조건

  • 처리 항목: ERP에서 제공하는 근무·출장·휴가·휴직 등의 상태, 복무 비고, 조회 대상 직원·부서 및 조회 기간
  • 처리 목적: 검색 결과의 근무 상태 표시와 복무현황 조회
  • 처리 방식: ERP 응답을 확장 프로그램에 전달하여 화면과 실행 중 메모리에서 처리합니다. 복무 비고 등은 원본 시스템이 제공하는 내용을 포함합니다. 연락처 검색 결과에서도 직원 사번을 이용하여 복무 상태를 연계 조회할 수 있습니다.

인증·연결 정보

  • 처리 항목: HR API 주소와 API Key, ERP의 기존 인증 세션, 조직도 연동에 사용하는 그룹웨어 페이지의 사용자 식별값 및 인증 관련 값
  • 처리 목적: 기관 API 인증과 권한 범위 내 ERP·그룹웨어 연동
  • 처리 방식: 사용자 배포판에 API 연결정보를 포함하며, 연결 설정은 Chrome 로컬 저장소에서도 처리합니다. 로그인 비밀번호를 별도로 입력받지 않습니다. ERP 요청은 브라우저가 관리하는 기존 로그인 세션을 사용하며, 확장 프로그램이 쿠키를 별도 조회·저장하는 기능은 없습니다.

사용자 설정과 기능 이용 정보

  • 처리 항목: 검색 유형별 최근 검색어, 즐겨찾기, 복무 조회 즐겨찾기와 조건, 표시 필드, 화면 설정, 자동 갱신 일정·실행 시각·결과 및 오류 메시지
  • 처리 목적: 반복 조회 편의, 사용자 환경 유지, 예약 갱신 및 실행 상태 안내
  • 처리 방식: 현재 Chrome 프로필의 로컬 저장소에 보관합니다.

기관 웹페이지 콘텐츠

  • 처리 항목: 조직도와 ERP 연동에 필요한 화면 요소, 직원·부서 선택 결과 및 조회 응답
  • 처리 목적: 조직도 표시, 복무 조회 및 화면 표시 조정
  • 처리 방식: 기관 웹페이지에 포함된 기존 기능과 패키지에 포함된 연동 함수를 이용합니다.

일반 웹사이트의 방문 목록을 기록하거나 클릭·마우스 이동·스크롤·키 입력을 감시하는 광고·분석 기능은 없습니다. 이메일 주소는 처리하지만 이메일·문자·채팅의 메시지 본문을 읽는 기능은 없습니다. API·ERP 응답과 무관하게 건강·금융·위치정보를 별도로 수집하는 기능은 없으며, 원본 응답의 부가 필드나 복무 비고는 위 처리 범위에 포함됩니다.

3. 정보의 저장 및 통신 대상

연락처 캐시, API 연결 설정, 검색기록, 즐겨찾기, 화면 설정, 갱신 설정 및 실행 결과는 현재 Chrome 프로필의 chrome.storage.local에 저장합니다. 조회 결과는 화면과 실행 중 메모리에서도 처리합니다.

기능 수행 시 다음과 같이 기관 시스템과 통신합니다.

  • HR API: 설정된 API 서버로 인증정보와 조회 파라미터를 전송하고 구성원·부서 정보를 수신합니다.
  • ERP: 기관 ERP 시스템에 직원·부서·기간 등의 조회 조건을 전송합니다. 해당 사이트의 기존 인증 세션을 사용합니다.
  • 그룹웨어: 기관 그룹웨어와 조직도 표시 및 관련 사용자·인증값을 이용한 화면 연동을 수행합니다.

개발자가 별도로 운영하는 수집·분석 서버에 연락처, 복무정보, 검색기록 또는 인증정보를 업로드하는 기능은 없습니다. 기관 시스템이 요청 과정에서 생성하는 접속·처리 로그는 해당 시스템의 관리 범위입니다.

4. 제3자 제공과 목적 외 이용

기관 API·ERP·그룹웨어에 대한 기능 수행 요청 및 사용자가 직접 실행하는 내보내기를 제외하고, 확장 프로그램은 사용자 데이터를 별도 제3자에게 전송하거나 판매하지 않습니다. 광고, 신용도 판단, 대출 심사 또는 구성원 정보 조회와 관계없는 목적으로 데이터를 이용·전송하지 않습니다.

사용자 데이터의 이용은 확장 프로그램에 명시된 구성원 정보 조회와 이를 지원하는 기능으로 제한합니다. 개인정보 처리를 위해 개발자가 별도 외부 분석·광고 서비스를 연결하거나 로컬 데이터를 외부 수탁 서버로 전송하는 기능은 없습니다.

5. 보관 기간과 삭제 방법

  • 연락처 캐시와 호출 대기 데이터: 갱신·초기화·확장 프로그램 제거 시까지 보관할 수 있습니다. 사용자에게 제공하는 데이터 초기화 기능으로 삭제할 수 있습니다.
  • 검색기록: 검색 유형별 최대 10개를 보관하며, 개별 삭제 또는 전체 삭제가 가능합니다.
  • 즐겨찾기·화면 설정·갱신 설정과 실행 결과: 사용자가 변경·삭제하거나 확장 프로그램을 제거할 때까지 보관할 수 있습니다. 별도의 기간 경과에 따른 자동 삭제 기능은 없습니다.
  • API 연결 설정: 데이터 초기화 후에도 유지됩니다. 확장 프로그램 제거 시 Chrome의 확장 프로그램 로컬 저장소와 함께 삭제됩니다. 배포 패키지에 포함된 연결정보는 설치 폴더와 배포 파일에 남을 수 있습니다.

옵션의 저장 데이터 초기화는 모든 설정을 삭제하는 기능이 아닙니다. 로컬 저장소 전체를 삭제하려면 확장 프로그램을 제거하세요. 자동 갱신을 계속 사용하는 경우 기관 데이터가 다시 수신될 수 있으므로 갱신을 중지하거나 확장 프로그램을 제거해야 합니다.

확장 프로그램을 제거해도 내보낸 CSV·JSON 파일, 별도로 보관한 배포 파일 및 기관 서버의 원본·로그는 삭제되지 않습니다. 사용자는 해당 파일을 직접 삭제해야 하며, 기관 원본 데이터의 보관·삭제는 해당 시스템 관리 정책을 따릅니다.

6. 내보내기 및 백업

사용자가 CSV 내보내기 또는 JSON 백업을 실행하면 해당 기기에 파일을 생성합니다. 파일에는 구성원 연락처, 설정, 검색기록 등이 포함될 수 있으며, 전체 백업에는 API 연결 설정과 인증정보가 포함될 수 있습니다. 백업 복원은 사용자가 선택한 파일의 데이터를 로컬 저장소에 반영합니다.

파일의 복사·공유·보관은 확장 프로그램의 통제 범위를 벗어나므로 기관의 정보 관리 기준에 따라 처리해야 합니다. 내보내기는 기관 데이터나 개인정보에 대한 제3자 제공 권한을 부여하지 않습니다.

7. 접근 권한과 보호 조치

  • storage: 연락처와 사용자 설정의 로컬 저장
  • alarms: 설정된 일정에 따른 연락처 갱신
  • tabs: ERP 탭 확인·열기·이동 및 로딩 확인
  • scripting: ERP·그룹웨어 페이지에서 조회와 표시 조정을 위한 연동 함수 실행
  • 호스트 권한: 사용자 배포판의 API 연결 설정에서 추출한 HTTP(S) 호스트와 기관 ERP·그룹웨어 호스트로 제한

기관 ERP와 그룹웨어는 HTTPS로 연결합니다. HR API의 통신 프로토콜은 배포 설정의 주소에 따르며, 패키징 도구는 HTTP와 HTTPS 주소를 모두 허용합니다. 호스트 권한은 Chrome의 처리 방식에 따라 해당 호스트 단위로 부여되며 경로·포트에 따른 세부 접근 제한을 보장하지 않습니다.

로컬 저장소와 내보낸 파일에 확장 프로그램이 별도의 암호화를 적용하지는 않습니다. 사용자 배포판의 API Key 인코딩은 분석을 통한 복원을 막는 비밀 보관 수단이 아닙니다. 배포 파일·백업·사용 기기는 기관의 접근 통제와 정보 관리 기준에 따라 관리해야 합니다.

확장 프로그램은 패키지에 포함된 연동 함수를 실행합니다. 조직도 연동에는 기관 웹페이지의 기존 JavaScript 함수와 jQuery.load()로 조직도 HTML을 불러오는 경로가 있으며, 해당 웹페이지의 스크립트가 실행될 수 있습니다. API JSON 응답을 eval 또는 Function으로 실행하지 않습니다.

8. 열람·정정·삭제 및 이용 중지

사용자는 옵션에서 저장된 연락처를 확인하고, 검색기록·즐겨찾기·화면 설정을 관리하며, 데이터 초기화와 확장 프로그램 제거를 통해 로컬 데이터를 삭제할 수 있습니다. 자동 갱신을 중지하거나 확장 프로그램을 사용 중지하여 추가 처리를 중단할 수 있습니다.

기관 HR·ERP 원본 정보의 정정·삭제와 접근 권한 변경은 해당 시스템 담당자에게 요청해야 합니다. 확장 프로그램은 원본 기관 데이터를 정정·삭제하는 기능을 제공하지 않습니다. 확장 프로그램의 데이터 처리 방식과 로컬 정보 관리에 관한 문의는 아래 개발자 연락처로 접수할 수 있습니다.
