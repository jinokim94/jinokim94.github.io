TIPA HR Contact Finder 개인정보처리방침

작성 기준일: 2026년 11월 9일 · 대상: v1.0.3 사용자 배포판

게시 전 확정할 초안입니다. 실제 HR API·ERP 응답에 포함되는 정보와 아래 내용이 일치하는지 확인한 뒤 게시하세요. 건강정보·금융정보·위치정보가 응답에 포함된다면 해당 항목과 처리 목적을 추가하고 스토어 신고도 갱신해야 합니다.

1. 목적과 대상

TIPA HR Contact Finder는 기관 내부 사용자가 업무에 필요한 구성원의 연락처, 조직도 및 복무정보를 조회하도록 돕는 Chrome 확장 프로그램입니다. 기관 내부 시스템의 접근 권한을 가진 사용자를 대상으로 합니다.

2. 처리하는 정보

  • 구성원 정보: HR API가 제공하는 이름, 사번, 전화번호, 이메일, 소속, 직위, 담당업무 및 기타 응답 필드. 선택한 표시 필드와 관계없이 응답의 행 전체를 로컬 캐시에 저장합니다.
  • 복무정보: ERP에서 조회하는 근무·출장·휴가·휴직 등 상태와 복무 비고, 직원·부서 및 조회 기간. 조회 결과는 화면 표시를 위해 처리합니다.
  • 인증·연결 정보: HR API 주소 및 API Key, ERP의 기존 로그인 세션, 조직도 연동에 필요한 그룹웨어 페이지의 사용자·인증 관련 값. 확장 프로그램은 로그인 비밀번호를 별도 입력받지 않으며, ERP 요청에는 브라우저가 관리하는 기존 세션을 사용합니다.
  • 이용 설정: 검색 유형별 최근 검색어, 즐겨찾기, 표시 필드, 조회 조건, 화면 설정, 자동 갱신 일정과 실행 결과.
  • 웹사이트 콘텐츠: 조직도 및 ERP 연동에 필요한 페이지 요소와 조회 응답.

일반 사이트의 방문 목록, 클릭·마우스 이동·스크롤·키 입력을 추적하는 분석 기능과 광고 추적 기능은 없습니다. 이메일 주소를 처리하지만 이메일·문자·채팅 메시지를 읽는 기능은 없습니다.

3. 이용 목적

정보는 구성원 검색, 관련 조직도·복무정보 표시, 연락처 갱신, 사용자 설정 유지, 사용자가 요청하는 내보내기 및 백업·복원에 사용합니다. 전용 목적과 관계없는 광고, 판매, 신용도 평가 또는 대출 판단에 사용하지 않습니다.

4. 저장과 전송

연락처 캐시, 연결 설정, 검색기록, 즐겨찾기 및 갱신 설정·결과는 현재 Chrome 프로필의 chrome.storage.local에 저장합니다. 조회 결과는 기능에 따라 화면과 실행 중 메모리에서도 처리합니다.

HR API 요청에는 설정된 인증정보와 조회 파라미터가 전송됩니다. ERP 요청에는 직원·부서·조회 기간 등의 조건과 기존 인증 세션이 사용됩니다. 조직도 표시를 위해 그룹웨어와 통신합니다. 개발자가 별도로 운영하는 수집·분석 서버로 업로드하는 기능은 없습니다. 기관 시스템의 서버 로그와 원본 데이터 보관은 해당 시스템의 운영 정책을 따릅니다.

사용자가 CSV 또는 JSON 백업을 만들면 해당 기기에 파일이 생성됩니다. 전체 백업에는 연결 설정과 인증정보가 포함될 수 있습니다. 로컬 저장과 배포판의 API Key 인코딩은 별도 암호화 보관을 보장하지 않습니다. 파일과 기기의 접근 권한을 적절히 관리해야 합니다.

5. 공유 및 제한된 이용

기능 수행에 필요한 기관 시스템 요청과 사용자가 직접 실행하는 내보내기 외에 사용자 데이터를 판매하거나 별도 제3자에게 전송하는 기능은 없습니다. 승인된 사용 사례를 제외한 제3자 판매·전송, 전용 목적과 무관한 사용·전송, 신용도 판단 및 대출 목적의 사용·전송을 하지 않습니다. 사용자 데이터의 이용은 Chrome 웹 스토어 사용자 데이터 정책의 제한된 이용 요건을 준수합니다.

6. 보관과 삭제

로컬 캐시와 설정은 갱신·초기화·삭제 또는 확장 프로그램 제거 시까지 보관될 수 있습니다. 검색기록은 검색 유형별 최대 10개를 보관하며 개별 삭제 또는 전체 삭제가 가능합니다. 옵션의 저장 데이터 초기화는 연락처 캐시·호출 대기 데이터·검색기록을 초기화하지만 연결 설정 등 모든 항목을 삭제하는 기능은 아닙니다. 확장 프로그램을 제거하면 확장 프로그램의 로컬 저장 데이터가 삭제됩니다.

내보낸 CSV·JSON 파일과 기관 서버의 원본·로그는 확장 프로그램을 제거해도 삭제되지 않습니다. 내보낸 파일은 사용자가 직접 삭제하고, 기관 원본 정보의 열람·정정·삭제 요청은 담당 관리자에게 문의해야 합니다.

7. 접근 권한 및 원격 페이지 연동

storage는 로컬 저장, alarms는 예약 갱신, tabs는 ERP 탭 연결, scripting은 기관 페이지 연동에 사용합니다. 현재 매니페스트의 호스트 범위는 <all_urls>이며 기능상 통신 대상은 설정된 HR API와 기관 ERP·그룹웨어입니다.

확장 프로그램은 패키지 내 함수를 주입하지만, 조직도 연동에서는 웹페이지의 기존 함수와 jQuery.load()를 통해 원격 조직도 HTML을 불러오는 경로도 사용합니다. 기관 웹페이지의 스크립트가 실행될 수 있습니다. API JSON 응답을 eval 또는 Function으로 실행하지 않습니다.
