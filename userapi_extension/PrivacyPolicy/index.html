TIPA HR Contact Finder 개인정보처리방침

시행일: 2026년 11월 9일 · 적용 대상: TIPA HR Contact Finder v1.0.3

1. 목적과 대상

본 개인정보처리방침은 개인 개발자 KimJinHyuk이 개발·운영하는 Chrome 확장 프로그램 TIPA HR Contact Finder(이하 “확장 프로그램”)에 적용됩니다. 확장 프로그램은 기관 내부 시스템의 접근 권한을 가진 사용자가 업무에 필요한 구성원의 연락처, 조직도 및 복무정보를 조회하도록 돕습니다.

이 방침은 확장 프로그램에서 처리하는 정보, 이용 목적, 저장·전송 방식 및 삭제 방법을 안내합니다. 기관의 HR API·ERP·그룹웨어 자체에서 처리하는 정보에는 해당 시스템의 운영 정책이 적용됩니다.

2. 처리하는 정보

  • 구성원 정보: HR API가 제공하는 이름, 사번, 전화번호, 이메일, 소속, 직위, 담당업무 등 HR API 응답에 포함되는 필드입니다. 화면에 표시하도록 선택한 필드뿐 아니라 응답의 행 전체를 기기의 로컬 캐시에 저장합니다.
  • 복무정보: ERP에서 조회하는 근무·출장·휴가·휴직 등 상태와 복무 비고, 직원·부서 및 조회 기간. 조회 결과는 화면 표시를 위해 처리합니다.
  • 인증·연결 정보: HR API 주소 및 API Key, ERP의 기존 로그인 세션, 조직도 연동에 필요한 그룹웨어 페이지의 사용자·인증 관련 값. 확장 프로그램은 로그인 비밀번호를 별도 입력받지 않으며, ERP 요청에는 브라우저가 관리하는 기존 세션을 사용합니다.
  • 이용 설정: 검색 유형별 최근 검색어, 즐겨찾기, 표시 필드, 조회 조건, 화면 설정, 자동 갱신 일정과 실행 결과.
  • 웹사이트 콘텐츠: 조직도 및 ERP 연동에 필요한 페이지 요소와 조회 응답.

일반 사이트의 방문 목록, 클릭·마우스 이동·스크롤·키 입력을 추적하는 분석 기능과 광고 추적 기능은 없습니다. 이메일 주소를 처리하지만 이메일·문자·채팅 메시지를 읽는 기능은 없습니다.

3. 이용 목적

정보는 구성원 검색, 관련 조직도·복무정보 표시, 연락처 갱신, 사용자 설정 유지, 사용자가 요청하는 내보내기 및 백업·복원에 사용합니다. 확장 프로그램의 기능 제공과 관계없는 광고, 데이터 판매, 신용도 평가 또는 대출 판단에 사용하지 않습니다.

4. 저장과 전송

연락처 캐시, 연결 설정, 검색기록, 즐겨찾기 및 갱신 설정·결과는 현재 Chrome 프로필의 기기 내 저장소(chrome.storage.local)에 저장합니다. 조회 결과는 기능에 따라 화면과 실행 중 메모리에서도 처리합니다.

HR API 요청에는 설정된 인증정보와 조회 파라미터가 전송됩니다. ERP 요청에는 직원·부서·조회 기간 등의 조건과 기존 인증 세션이 사용됩니다. 조직도 표시를 위해 그룹웨어와 통신합니다. 개발자가 별도로 운영하는 수집·분석 서버로 업로드하는 기능은 없습니다. 기관 시스템의 서버 로그와 원본 데이터 보관은 해당 시스템의 운영 정책을 따릅니다.

사용자가 CSV 또는 JSON 백업을 만들면 해당 기기에 파일이 생성됩니다. 전체 백업에는 연결 설정과 인증정보가 포함될 수 있습니다. 기기 내 저장 데이터와 백업 파일에는 별도의 암호화 보관이 보장되지 않습니다. 배포판에서 API Key를 인코딩하더라도 이를 암호화된 보관으로 볼 수 없습니다. 사용자는 파일과 기기의 접근 권한을 관리하고 인증정보가 포함된 백업 파일을 외부에 공유하지 않도록 주의해야 합니다.

5. 공유 및 제한된 이용

확장 프로그램은 기능 수행에 필요한 기관 시스템과의 통신 및 사용자가 직접 실행하는 내보내기 외에 사용자 데이터를 별도 제3자에게 전송하지 않으며, 사용자 데이터를 판매하지 않습니다.

사용자 데이터는 이 방침에 명시된 기능 제공 목적으로만 이용하며, 기능 제공과 관계없는 광고, 신용도 판단 또는 대출 목적에 이용하거나 전송하지 않습니다. TIPA HR Contact Finder의 사용자 데이터 이용 및 전송은 Chrome 웹 스토어 사용자 데이터 정책의 제한된 이용(Limited Use) 요건을 준수합니다.

6. 보관과 삭제

로컬 캐시와 설정은 갱신·초기화·삭제 또는 확장 프로그램 제거 시까지 보관될 수 있습니다. 검색기록은 검색 유형별 최대 10개를 보관하며 개별 삭제 또는 전체 삭제가 가능합니다. 옵션의 저장 데이터 초기화는 연락처 캐시·호출 대기 데이터·검색기록을 초기화하지만 연결 설정 등 모든 항목을 삭제하는 기능은 아닙니다. 확장 프로그램을 제거하면 확장 프로그램의 로컬 저장 데이터가 삭제됩니다.

내보낸 CSV·JSON 파일과 기관 서버의 원본·로그는 확장 프로그램을 제거해도 삭제되지 않습니다. 내보낸 파일은 사용자가 직접 삭제하고, 기관 원본 정보의 열람·정정·삭제 요청은 담당 관리자에게 문의해야 합니다.

7. 브라우저 권한과 기관 시스템 연동

확장 프로그램은 다음 권한을 기능 제공에 사용합니다.

  • 저장소(storage): 연락처 캐시와 사용자 설정 등의 기기 내 저장
  • 예약 실행(alarms): 설정한 일정에 따른 연락처 갱신
  • 탭(tabs): ERP 탭 연결
  • 스크립트 실행(scripting): 기관 웹페이지와의 기능 연동
  • 호스트 접근: 현재 선언된 접근 범위는 <all_urls>이며, 기능상 통신 대상은 사용자가 설정한 HR API와 기관 ERP·그룹웨어입니다. 이 권한을 일반 웹사이트의 이용 행태나 광고 추적에 사용하지 않습니다.

조직도와 ERP 연동 과정에서 기관 웹페이지의 요소와 조회 응답을 처리합니다. 조직도는 기관 웹페이지의 기존 기능을 이용해 원격 페이지 내용을 불러오며, 이 과정에서 기관 웹페이지의 스크립트가 실행될 수 있습니다. HR API의 JSON 응답을 실행 코드로 처리하지 않습니다.
