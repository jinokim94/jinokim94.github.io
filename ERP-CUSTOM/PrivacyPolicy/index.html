업무도우미 개인정보처리방침

시행일 및 최종 수정일: 2026년 11월 16일

업무도우미는 지정된 사내 포털·ERP·그룹웨어·메일·규정 사이트의 검색, 메뉴 구성, 표 표시 및 첨부파일 확인을 돕는 Chrome 확장 프로그램입니다. 기능 제공에 필요한 정보는 주로 사용자의 브라우저에서 처리하며, 개발자가 운영하는 별도 수집 서버로 전송하지 않습니다.

1. 적용 범위

이 방침은 업무도우미 확장 프로그램과 그 안의 미리보기 기능에 적용됩니다. 연결된 업무 시스템과 Chrome 웹스토어·GitHub 등 외부 서비스 자체의 정보 처리는 각 서비스의 정책을 따릅니다. 확장 프로그램에서 제외된 출장 정산서 및 서명 이미지 기능은 이 방침의 대상에 포함되지 않습니다.

2. 처리하는 정보와 목적

  • 설정 정보: 기능 사용 여부, 화면 구성, 메뉴 순서, 열 표시·너비, 즐겨찾기 및 알림 설정 등을 저장해 사용자 설정을 유지합니다.
  • 개인식별정보: 사용자가 입력한 기안자 이름, 기존 업무 화면의 사용자 ID·직원 정보 등을 검색, 화면 표시 및 기존 시스템 요청에 필요한 범위에서 처리합니다.
  • 업무 및 금융 관련 정보: 예산·배정·발의·결의·집행 금액 등 화면의 업무 정보를 읽어 잔액 계산, 표 표시 및 검색을 제공합니다. 결제 대행이나 신용 평가에는 사용하지 않습니다.
  • 문서 및 커뮤니케이션: 메일·그룹웨어 문서·첨부파일의 내용과 메타데이터, 검색 입력값 등을 검색 및 미리보기에 필요한 범위에서 처리합니다. 사용자가 첨부할 파일이나 클립보드 내용을 제공하면 첨부 기능 수행에 사용합니다.
  • 인증 관련 정보: 첨부 조회 시 기존 화면의 인증 토큰을 읽어 해당 업무 시스템 요청에 전달할 수 있습니다. 브라우저는 요청에 기존 로그인 쿠키를 포함할 수 있습니다. 암호화된 문서의 미리보기를 위해 사용자가 입력한 문서 암호는 브라우저 내 복호화에 사용하며, 확장 프로그램이 별도로 영구 저장하지 않습니다.
  • 페이지 및 파일 주소: 적용할 기능 판단, 탭 연결, 파일 조회 및 미리보기 전달을 위해 현재 업무 페이지와 첨부파일의 URL을 처리할 수 있습니다. 전체 웹 방문 이력이나 사용자 행동 분석 기록을 구축하지 않습니다.

위치 추적이나 건강정보 분석 기능은 제공하지 않습니다. 다만 사용자가 여는 문서에는 여러 유형의 정보가 포함될 수 있으며, 미리보기는 해당 파일 내용을 표시하기 위해 처리합니다.

3. 저장 위치와 보관 기간

  • 설정과 일부 기능 데이터는 Chrome의 확장 프로그램 저장소, 업무 사이트의 로컬 저장소 또는 세션 저장소에 보관됩니다. 설정 변경·초기화, 해당 저장소 삭제 또는 세션 종료 등 저장 방식에 따른 시점까지 유지될 수 있습니다.
  • 첨부파일 미리보기에서는 파일 데이터·파일명·형식·원본 페이지 URL 등이 브라우저의 IndexedDB에 임시 저장될 수 있습니다. 뷰어가 데이터를 가져가면 해당 임시 파일 레코드는 삭제됩니다. 읽히지 않은 데이터는 이후 새 임시 보관이 시작될 때 생성 후 1시간이 지난 항목을 정리합니다. 정확히 1시간 뒤 자동 삭제되는 방식은 아닙니다.
  • 뷰어가 사용하는 파일 데이터는 표시 중 메모리에 남을 수 있습니다. 사용자가 직접 내려받거나 저장한 파일은 사용자가 삭제할 때까지 기기에 남습니다.

4. 전송 및 제3자 제공

검색, 업무 조회 및 첨부파일 불러오기에 필요한 요청은 기존 업무 시스템으로 전송됩니다. 이때 해당 시스템이 요구하는 검색값, 식별자 또는 인증정보가 포함될 수 있습니다. 이는 사용자가 접근 가능한 업무 기능을 제공하기 위한 처리입니다.

개발자는 확장 프로그램을 통해 정보를 별도 서버에 수집하거나 판매하지 않으며, 광고·행동 분석 또는 신용도·대출 심사 목적으로 사용하거나 제공하지 않습니다. AI 서비스로 문서나 화면 내용을 전송하는 기능도 제공하지 않습니다.

5. 권한 사용

  • scripting: 선택한 기능을 지정된 업무 페이지와 프레임에 등록·실행하고, 사용할 수 있는 작업을 확인합니다.
  • tabs: 현재 배포본에서 요청하는 권한으로, 업무 탭 연결 및 사용자가 요청한 새로고침 등 탭 관련 처리에 사용됩니다.
  • 호스트 접근: 지정된 사내 업무 사이트에서 화면 개선과 파일 조회를 수행합니다. 사용자는 Chrome의 확장 프로그램 설정에서 사이트 접근 권한을 제한할 수 있으며, 제한한 사이트에서는 관련 기능이 동작하지 않을 수 있습니다.

6. 사용자의 선택과 삭제

사용자는 확장 프로그램 설정에서 개별 기능을 끌 수 있습니다. 이미 열린 페이지에서는 새로고침이나 창을 다시 여는 과정이 필요할 수 있습니다. 각 기능에서 제공하는 초기화를 사용하거나 Chrome의 사이트 데이터 및 확장 프로그램 저장소를 삭제해 저장된 데이터를 지울 수 있습니다.

확장 프로그램을 제거해도 업무 사이트의 로컬 저장소나 직접 저장한 파일이 모두 삭제되는 것은 아닙니다. 필요하면 해당 업무 사이트의 사이트 데이터와 다운로드 파일을 별도로 삭제해 주세요.

확장 프로그램은 기존 업무 시스템의 접근 권한과 로그인 상태에 따라 동작하며, 권한이 없는 자료에 대한 접근을 제공하기 위한 도구가 아닙니다. 사용자는 기기 및 브라우저의 접근 권한을 적절히 관리해야 합니다.

업무도우미의 사용자 데이터 사용은 제한적 사용 요건을 포함한 Chrome 웹스토어 사용자 데이터 정책을 준수합니다. 정보는 이 방침에 설명한 사용자 기능을 제공하는 범위에서 사용합니다.
