# jinokim94 personal homepage

GitHub Pages용 정적 개인 홈페이지. 외부 라이브러리나 빌드가 필요하지 않습니다.

## 수정
- `index.html`: 홈페이지 콘텐츠
- `style.css`: 반응형 스타일
- 프로젝트를 추가할 때 `projects/<slug>/index.html`, `guide.html`, `privacy.html` 경로를 권장합니다.
- 공개 승인을 받은 프로젝트 정보만 추가합니다. 비공개 저장소나 백업 파일을 복사하지 않습니다.
- 개인정보처리방침은 실제 수집 항목, 목적, 보유 기간, 제3자 제공, 외부 서비스, 담당자 연락처를 확인한 후 작성합니다.

## 배포
저장소 `jinokim94/jinokim94.github.io`의 `main` 브랜치 루트를 Pages 게시 원본으로 사용합니다.
